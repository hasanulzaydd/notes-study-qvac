Python basics - self study notes

- python is dynamically typed, don't need to declare types like in Java/C.
  var = 5 then var = "hi" later is totally fine, type just changes.

- indentation matters!! no curly braces, blocks are defined by whitespace.
  mixing tabs and spaces breaks everything, learned that the hard way.

- lists are mutable (can change after creating), tuples are NOT — once you
  make a tuple you can't change its items. lists use [ ], tuples use ( ).

- dictionaries = key/value pairs, like {"name": "sam", "age": 20}. from
  python 3.7+ they keep insertion order btw, didn't used to.

- functions defined with def, use return to send back a value. if no
  return, function just gives back None by default.

- for loops iterate over anything iterable (lists, strings, ranges, dict
  keys...). range(5) goes 0,1,2,3,4 — stops BEFORE the number you give it.

- list comprehension: [x*2 for x in range(5)] — shorthand way to build a
  list instead of a for loop + append. faster and more "pythonic"

- == checks value equality, "is" checks if it's literally the same object
  in memory. mixed these up on the quiz last time.

- exceptions: try/except blocks. can catch specific errors like
  except ValueError: or just except: for anything (not great practice tho)

- packages installed with pip, virtual envs (venv) keep project deps
  separate so they don't clash between projects
